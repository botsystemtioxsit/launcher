# БАТТЛ Лаунчер

Приложение для Windows (`.exe`): входишь в аккаунт, и оттуда ставишь,
обновляешь, запускаешь и удаляешь приложения проекта — **Тролль-Баттл** и
**БАТТЛ Админ**. Сам лаунчер тоже обновляется сам.

## Как поставить
Releases → последний релиз → `BattleLauncher-Setup-<версия>.exe` → запустить.
Установка на пользователя, права администратора не нужны.

## Вход
Тот же вход, что в игре и админ-панели, — без паролей и без Firebase Auth:
1. Вводишь email, привязанный к аккаунту в игре (Настройки → Аккаунт).
2. Лаунчер кладёт заявку `users/<id>/loginRequests/<id>` и просит бота написать
   владельцу аккаунта.
3. Нажимаешь «Разрешить» в Telegram (или в игре → Сообщество → Запросы, или в
   админ-панели → Аккаунт). Ждать можно 5 минут.

Аккаунтов можно держать несколько (раздел «Аккаунт»). «БАТТЛ Админ» виден только
ролям `moderator` / `admin` / `superadmin`; роль перепроверяется по базе перед
каждой установкой и запуском.

## Как это работает
- Версии берутся из релизов GitHub репозиториев `index.html` и `battle-admin-bot`
  (их публикует `build-windows-installer.yml`).
- Установщик скачивается только с `github.com/botsystemtioxsit/<репо>/releases/…`,
  сверяется по sha512 из `latest.yml` и запускается тихо (`/S`).
- Установленную версию лаунчер читает из списка «Установка и удаление программ».

## Разработка
```bash
npm install
npm run check   # быстрая проверка без Electron
npm start       # окно (установка работает только в Windows)
```
Выпуск: поднять `version` в `package.json` и запушить в `main` — Actions соберёт
`.exe` и опубликует релиз.
