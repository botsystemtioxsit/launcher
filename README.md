# Ghost Shell Launcher

Нативное приложение для Windows (C# / .NET 8, WPF) — не Electron и не браузер.
Один файл `BattleLauncher.exe`, .NET внутри, ничего ставить не нужно.

Вход в аккаунт, а оттуда установка, обновление, запуск и удаление приложений
проекта — **Тролль-Баттл**, **ВидеоЧат** и **Ghost Shell Terminal**. Сам лаунчер обновляется сам.

## Как получить
Releases → последний релиз → `BattleLauncher.exe` → запустить → «Да» на вопрос про установку
(ярлыки в «Пуске» и на рабочем столе, запись в «Установленные приложения», удаление оттуда же).

## Ghost Shell Terminal (`Terminal/`)
Админ-панель проекта в виде Windows-приложения (`TIOXSITTerminal.exe`, WPF + Edge WebView2), лежит в том же релизе,
что и лаунчер. Показывает ту же самую страницу админ-панели, что и сайт (`battle-admin-bot`, GitHub Pages) — один в один,
со всеми разделами; обновляется сама вместе с сайтом. Вход общий с лаунчером: при первом запуске аккаунт и deviceId
переносятся в страницу один раз (флаг `tioxsitSeeded`), дальше вход/выход/смена аккаунта — как в обычной панели.
Нужен компонент WebView2 (есть в Windows 11 и в большинстве Windows 10; иначе окно предложит скачать).

## Браузерные и EXE-версии
Сейчас приложения проекта (Тролль-Баттл, ВидеоЧат, Ghost Shell Terminal) — это окна вокруг живых страниц, поэтому кнопка
называется «Скачать браузерную версию». Рядом кнопка «Скачать EXE-версию»: у «Ghost Shell Terminal» она ставит настоящую программу «TIOXSIT Terminal»
(из релиза лаунчера, с проверкой контрольной суммы; запуск, обновление и удаление там же). У остальных приложений кнопка
заблокирована, пока не выйдут их нативные версии.

## Вход
Те же способы, что в админ-панели (кроме входа через Telegram — он есть только внутри самого Telegram):
1. **По почте** — email, привязанный в игре (Настройки → Аккаунт). Лаунчер кладёт заявку
   `users/<id>/loginRequests/<id>` и просит бота написать владельцу; он нажимает «Разрешить»
   (Telegram, игра → Сообщество → Запросы или админ-панель → Аккаунт). Ждать можно 5 минут.
2. **По токену доступа** — его выдаёт Супердоступ. Входит сразу, без аккаунта; открывает только
   «Ghost Shell Terminal». Отозван или истёк — лаунчер сам выйдет при следующей проверке.
3. **По коду устройства** — лаунчер показывает 6-значный код; его отправляют боту TerminalBot в Telegram
   обычным сообщением (или вводят в админ-панели: «Аккаунт» → «Подключить устройство по коду»). Это устройство владелец может отозвать — тогда
   лаунчер выйдет из аккаунта сам.

Аккаунтов можно держать несколько. «Ghost Shell Terminal» виден только ролям `moderator` / `admin` /
`superadmin` и токенам доступа; роль перепроверяется по базе перед каждой установкой и запуском.
Токен и deviceId хранятся в файле только зашифрованными (Windows DPAPI, ключ текущего пользователя).

## Единый вход в приложениях (план)
Когда игра и админ-панель станут нативными: вошёл в лаунчере — в установленных через него
приложениях входить заново не нужно. Задумано так: общая маленькая библиотека (`BattleAuth`) читает
сессию лаунчера (зашифрованный файл DPAPI в профиле пользователя: тип входа, id, токен/deviceId),
приложение само перепроверяет её по базе, как лаунчер (роль, бан, отзыв токена/устройства). Выход
в лаунчере стирает сессию. Пока приложения — окна Electron, этого нет.

## Как это работает
- Версии приложений — из релизов GitHub репозиториев `index.html` и
  `battle-admin-bot` (`latest.yml`: версия, имя файла, sha512).
- Установщик скачивается только с `github.com/botsystemtioxsit/<репо>/releases/…`,
  сверяется по sha512 и запускается тихо (`/S`).
- Установленную версию лаунчер читает из списка «Установка и удаление программ».
- Самообновление: последний релиз этого репозитория, `BattleLauncher.exe` +
  `.sha256`; старый файл переименовывается в `.old`, новый встаёт на место.

## Сборка
Только через GitHub Actions (`.github/workflows/build-windows.yml`): пуш в любую
ветку собирает и кладёт файл в артефакты, пуш в `main` публикует релиз
`v<версия из Launcher/Launcher.csproj>`. Локально: `dotnet publish Launcher -c Release -r win-x64`.
