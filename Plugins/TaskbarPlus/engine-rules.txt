# Группы:
#   bgfill   — фон панели          bgstroke — тонкая обводка панели

#   system   — часы, язык, сеть, звук, скрытые значки: всегда один объект
#   pill     — собственная плашка значка внутри системной области (её гасим, чтобы область была одним блоком)
# Плагин скачивает этот файл при запуске (raw.githubusercontent.com, ветка main): так названия элементов
