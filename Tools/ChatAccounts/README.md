# Ghost Shell · Chat Accounts

Программа для Windows: подключаете **свои** аккаунты Telegram и запускаете для них **скрипты** — наборы настроек
из закрытого списка действий. Работает на вашем компьютере, пока открыта.

**Что умеет:** регулярные сообщения в ваши чаты (несколько текстов, интервал ≥ 10 мин, лимит в сутки, тихие часы),
приветствие новичков в самом чате, ответы по ключевым словам.

**Чего не делает (зашито в `engine.py`, проверяется тестами):** не собирает списки участников, не пишет в личку,
не вступает в чаты и не добавляет людей, не выполняет произвольный код.

Вход в аккаунт хранится в `%APPDATA%\GhostShellChatAccounts` зашифрованным средствами Windows (DPAPI).
Нужны `api_id`/`api_hash` с my.telegram.org. Telegram может ограничить личный аккаунт — лимиты это снижают, но не отменяют.

Проверка: `pip install telethon && python -m unittest discover -s tests`. Сборка `.exe` — workflow `build-chat-accounts.yml`.
