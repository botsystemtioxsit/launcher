# Lock Screen Custom Plus

Самописное приложение владельца: живые обои для экрана блокировки (часы за фигурой человека, шрифты, погодные эффекты, стикеры, стили).
Здесь — старая собранная версия (`original/`) и то, что из неё восстановил декомпилятор (`decompiled/`). Исходного кода и ключа подписи не сохранилось.

## Новая версия (`app/`)
Приложение собрано заново из восстановленного кода: пакет `com.lockscreen.customplus` в исходниках, но на телефоне оно ставится как **`com.tioxsit.lockscreenplus`** («Lock Screen Plus») — рядом со старым.
Что добавлено к старому:
- **Экран «на боку»**: когда телефон лежит на боку, обои показывают отдельный вид (по умолчанию — часы на тёмном фоне, повёрнутые как надо). Настраивается отдельно: вкладка «Режимы» → «Какой экран настраиваем → На боку».
- **Статистика по USB**: пока подключён кабель — панель (часы, заряд, ток, напряжение, температура, память, график, журнал событий). Вкладка «Режимы» → «Пробный показ» показывает её с настоящими данными без кабеля.
Сборка: GitHub Actions `build-lockscreen.yml` → релиз `lockscreen-plus-latest` (`LockScreenPlus.apk`).
Старый APK — в `original/`.
