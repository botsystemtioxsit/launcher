# Проверка расширения Mask Plus (Chromium + Playwright)

Windows не нужен: расширение — обычные файлы, его можно проверить в настоящем Chromium прямо из этой среды.

- `run.js [CC,CC…]` — сравнивает подмену с «родной» (эмуляция Playwright: `timezoneId` + `locale`) для всех стран из
  `tools/mask-plus/countries.json`: 10 дат (в том числе переходы на летнее время и 1950 год), около 150 вызовов
  `Date`/`Intl` на каждую. Известные границы (в самом тесте помечены): название пояса в скобках у дат до 1970 года и у
  языков, для которых в сборке нет данных ICU (az…); `Intl.DateTimeFormat().resolvedOptions().locale` для `nb-NO` даёт `nb`;
  у сборки Chromium из тестовой среды нет данных для `is`, `ka`, `hy` — их сравнение пропускается.
- `run2.js` — функциональные проверки: заголовок Accept-Language, геолокация, iframe (в том числе синхронный
  `contentWindow` и другой сайт), «как родное» в `toString()`, отдельные переключатели, исключённый сайт, WebRTC,
  выключение, окно расширения (скриншоты в `SHOTS_DIR` или во временную папку).
